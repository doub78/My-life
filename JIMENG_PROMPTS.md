## HOW TO USE IN JIMENG AI

1. Go to jimeng.jianying.com
2. Select **Video Generation**
3. Paste the prompt in the text box
4. Set: **5 seconds**, **16:9**, **Cinematic** style
5. Paste the negative prompt in the negative prompt box
6. Generate — if result is off, add "photorealistic, cinematic film, documentary style" at the start
