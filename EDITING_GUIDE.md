## CapCut Tips for This Style
1. **Location pins** — Use CapCut text → add red map pin emoji + location name
2. **Stats overlay** — White bold text on semi-transparent dark bar
3. **Company logos** — Add as sticker/image overlay on top of footage
4. **POISON label style** — Use CapCut stickers or import custom PNG
5. **Transitions** — Hard cuts only (no fades) — matches the dark punchy style
6. **Color grade** — Add slight desaturation + contrast boost to all clips for uniform look
